# Contributing Guide

本リポジトリでは、エルテクメソッドの改善提案・レビューを歓迎します。
ただし、品質維持のため以下のルールに従ってください。

---

## 1. 基本方針

- 本資料は思想を含みます
- 思想の違いによる意見は歓迎します
- ただし、必ず「理由」と「改善案」をセットで提示してください

---

## 2. ブランチルール

- mainブランチへの直接コミットは禁止です
- 必ずブランチを作成して作業してください

### ブランチ命名例

- fix/xxx
- improve/xxx
- review/xxx

---

## 3. Pull Requestルール

すべての変更はPull Request経由で行ってください

### 必須記載内容

Pull Requestには以下を記載してください

```markdown
## 概要
変更内容を記載

## 理由
なぜ修正が必要か

## 変更内容
どのように改善されたか
