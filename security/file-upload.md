# ファイルアップロード

---

## 1. ルール（要約）

- ファイル名を信用してはいけない
- 拡張子だけで判定してはいけない
- 保存先を制限する
- 実行可能ファイルを許可しない
- アップロードサイズを制限する
- 美しいコードとは安全で可読性の高いコードである

---

## 2. 解説

### セキュアコーディングのお作法（その１０：アップロードファイルを信用しない）

アップロードされたファイルは
外部入力です。

したがって信用してはいけません。

---

### 悪い例

```java
String fileName =
    file.getOriginalFilename();

file.transferTo(
    new File(fileName)
);
```

ファイル名をそのまま利用しています。

---

### 問題点

攻撃者は

```text
../../config.txt
```

のようなファイル名を指定できる可能性があります。

---

### 正しい例

```java
String fileName =
    UUID.randomUUID().toString();
```

システム側で保存名を生成します。

---

### 拡張子判定は不十分

以下のようなファイルが存在します。

```text
test.jpg.exe
```

ファイル内容も確認してください。

---

### サイズ制限

以下を必ず制御してください。

- ファイルサイズ
- ファイル数
- 保存容量

---

### まとめ

アップロードファイルは信用してはいけません。

ファイル名、
内容、
サイズを検証してください。

美しいコードとは、
安全で可読性の高いコードであると考えます。
