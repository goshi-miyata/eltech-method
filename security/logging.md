# ログ出力

---

## 1. ルール（要約）

- ログへ機密情報を出力してはいけない
- ログへユーザ入力をそのまま出力してはいけない
- ログは障害調査に利用できる内容とする
- パスワードやトークンは出力しない
- 美しいコードとは安全で可読性の高いコードである

---

## 2. 解説

### セキュアコーディングのお作法（その４：ログは全員が読む）

ログは開発者だけが見るものではありません。

運用担当者、
保守担当者、
セキュリティ担当者も参照します。

そのため出力内容には注意が必要です。

---

### 悪い例

```java
logger.info(
    "login user={} password={}",
    userId,
    password
);
```

パスワードを出力してはいけません。

---

### 悪い例

```java
logger.info(
    request.getParameter("name")
);
```

ユーザ入力を無加工で出力しています。

ログ改ざんや調査妨害の原因になります。

---

### 正しい例

```java
logger.info(
    "user login. userId={}",
    userId
);
```

ログは

- 誰が
- 何をしたか

が分かれば十分です。

---

### まとめ

ログは重要です。

しかし記録すべきなのは
機密情報ではなく行動履歴です。

美しいコードとは、
安全で可読性の高いコードであると考えます。
