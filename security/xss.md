# クロスサイトスクリプティング（XSS）

---

## 1. ルール（要約）

- ユーザ入力をそのまま出力してはいけない
- HTMLへ出力する場合はエスケープする
- JavaScriptへ動的文字列を埋め込まない
- 出力時に無害化する
- 美しいコードとは安全で可読性の高いコードである

---

## 2. 解説

### セキュアコーディングのお作法（その６：出力を信用しない）

入力値検証を行っていても、
XSSは発生します。

なぜなら問題は入力ではなく
出力で発生するからです。

---

### 悪い例

```java
out.print(userName);
```

例えば以下のような入力を受けた場合、

```html
<script>alert('xss')</script>
```

ブラウザ上でスクリプトが実行される可能性があります。

---

### 正しい例

```java
out.print(
    StringEscapeUtils.escapeHtml4(
        userName
    )
);
```

HTMLとして出力する際は
必ずエスケープしてください。

---

### よくある誤解

```text
入力チェックしているから大丈夫
```

これは誤りです。

XSS対策の基本は

出力時エスケープ

です。

---

### まとめ

ユーザ入力をそのまま画面へ表示してはいけません。

出力時には必ずエスケープ処理を行ってください。

美しいコードとは、
安全で可読性の高いコードであると考えます。
