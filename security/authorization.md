# 認可

---

## 1. ルール（要約）

- 認証と認可を混同してはいけない
- 利用者権限を必ず確認する
- 画面制御だけで権限制御してはいけない
- サーバ側で認可判定を行う
- 美しいコードとは安全で可読性の高いコードである

---

## 2. 解説

### セキュアコーディングのお作法（その９：誰でも実行できてはいけない）

認証と認可は異なります。

認証は

```text
誰か
```

を確認します。

認可は

```text
何ができるか
```

を確認します。

---

### 悪い例

```java
deleteUser(id);
```

ログイン済みであれば
誰でも実行できてしまいます。

---

### 正しい例

```java
if(hasAdminRole(user))
{
    deleteUser(id);
}
```

権限確認を行います。

---

### 画面制御だけでは駄目

```text
管理者ボタンを非表示
```

だけでは不十分です。

URLを直接実行される可能性があります。

---

### まとめ

認可はサーバ側で判定してください。

画面だけで権限制御してはいけません。

美しいコードとは、
安全で可読性の高いコードであると考えます。
