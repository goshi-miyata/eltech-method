# 範囲条件

---

## 1. ルール（要約）
- 範囲条件は直感的に理解できる形で記述する
- 数学的な表現に近い形で条件を書く
- 可読性の低い順序の条件は使用しない
- 美しいコードとは可読性の高いコードとなる

---

## 2. 解説（原文）

### コーディングのお作法（その７：IF文で範囲条件したい場合）

よく、０～１２までは、真という処理があります。
数学的に書けば、値をＸとすると
    ０≦Ｘ≦１２
となります。
これをif文で表すとどうなるでしょう？
まずは、悪い例から

```java
    if (X >= 0 && X <= 12)
```

です。    
何が悪いかわかりますか？
何度も言いますが、直感的ではないからです。
    ０≦Ｘ≦１２
    if (X >= 0 && X <= 12)
よく比べて下さい。
もしも、前者のようなコードが書ければ、
間違いなく、前者のようなコードを書くはずです。
なぜなら、直感的だからです。

では、正解コード
```java
    if (0 <= X && X <= 12)
```
これは、値Ｘが０～１２の間でなければならない事を
如実に表しています。

常に、直感的にわかりやすい記述をしましょう。



美しいコードというのは、大前提として可読性の高いコードとなります。
