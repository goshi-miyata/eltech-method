# 三項演算子

---

## 1. ルール（要約）
- 三項演算子の使用は可読性を基準として判断する
- 可読性が高い場合のみ三項演算子を使用する
- 複雑な処理や長い文になる場合はif文を使用する
- 美しいコードとは可読性の高いコードである

---

## 2. 解説（原文）

### コーディングのお作法（その３：三項演算子の使い方）

三項演算子はとても有益なコードで使う事に制限はすべきでないと考えています。
但し、以下に気をつけなければなりません。

三項という位ですから、３つの部位により成り立ちます。
その可読性の有無を使用判定の基準としてください。

例えば、以下のコードです。

```java
    msg = ret ? "OK": "NG";
```

これを
```java
    if(ret)
    {
        msg = "OK";
    }
    else
    {
        msg = "MG";
    }
```
と書いたら・・・先のコードに比べ、とたんに見難いコードとなります。


では、下記は同でしょう。

```java
    msg = IsAbsolutekasadflaj(A,B,C) ? "確認できました。このまま処理を続けてください。Result=[true]": "異常値を確認しました。このまま処理は続行できません。。Result=[false]")
```

これ、読めますか？
つまりこの場合は、

    
```java
    if(IsAbsolutekasadflaj(A,B,C))
    {
        msg = "確認できました。このまま処理を続けてください。Result=[true]";
    }
    else
    {
        msg = "異常値を確認しました。このまま処理は続行できません。。Result=[false]";
    }
```

とするのが正しくなります。
品質を高くする為には、まず、可読性の確保が先決です。
常に、可読性の高いコードを記載するように心がけてください。

美しいコードというのは、大前提として可読性の高いコードとなります。
